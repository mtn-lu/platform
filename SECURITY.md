# Reporting security issues

Do not post credentials, session cookies, login links, personal data, or exploit details in a public issue. Use this repository's private vulnerability reporting when enabled; otherwise contact the repository owner privately through the contact method on their GitHub profile. Private reporting must be enabled in GitHub settings; this file does not enable it.

This foundation has not been deployed or independently security-audited. See [security assumptions](docs/security.md) and [verification results](docs/verification.md), including checks that could not run. Supported scope is the current main branch; review dependency updates promptly.
